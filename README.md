# Klasifikasi_Citra_Emosi_Wajah_Menggunakan_CNN1
Klasifikasi emosi wajah merupakan penerapan teknologi Computer Vision untuk mengenali ekspresi manusia melalui pola visual pada wajah. Proyek ini menggunakan metode Convolutional Neural Network (CNN) untuk mengklasifikasikan berbagai ekspresi emosi, seperti senang, sedih, marah, takut, terkejut, dan netral berdasarkan citra wajah secara otomatis.
